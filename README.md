# BMSTU-Cheprasov-mini-project
Небольшой командный проект в рамках дисциплины "Программирование"
В репозитории только часть с Управляющим устройством(УУ) - клиент-серверным маршрутизатором команд
---

Система представляла из себя распределенный комплекс, состоящий из следующих компонентов:
1. УУ - принимает команды от клиентов или через stdin, анализирует типы данных, определяет целевой модуль исполнения и направляет запросы по TCP.
2. APU - модуль выполнения целочисленных операций.
3. FPU - модуль выполнения операций над числами с плавающей точкой.
4. DB - база данных, куда можно было сохранить результат вычислений, для последующего использования в командах.
5. Сервер-счетчик - модуль учета команд и управления переходами (команда JMP). 

Команды передаются в текстовом формате:
```text
<команда> <маска типов> <аргумент_1> [<аргумент_2>] [<ключ_результата>]
```
Целочисленные операции:
- sum - сложение;
- sub - вычитание;
- mul - умножение;
- div - деление;
- cmp - сравнение;
- neg - инверсия знака.

Операции с плавающей точкой (если хотя бы один из аргументов float):
- add - сложение;
- sub - вычитание;
- div - деление;
- sin - синус;
- cmp - сравнение.

Типы аргументов: 
- i - целочисленный;
- f - число с плавающей точкой;
- r - строковый ключ для получения значения из базы данных.

Управляющие команды:
- exit;
- JMP.

---

## Сборка и запуск

1. Сборка проекта:
```bash
make
```

2. Запуск mock-серверов
```bash
./bin/test_server
```

3. Запуск УУ в другом терминале
```bash
./bin/server
```

4. Развлекайтесь, насколько УУ без остальных компонентов комплекса позволяет
